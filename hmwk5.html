Ex. 1 – Riemann and Lebesgue Integration

Riemann integration partitions the domain into subintervals and adds rectangle areas. A Lebesgue integral groups points according to their function values: it partitions the range and measures the preimages of those range bins.

Riemann midpoint sum

Σ f(xᵢ*) Δx

The midpoint of each domain interval is sampled.
Lebesgue-inspired range sum

Σ yⱼ · measure({x : f(x) ∈ binⱼ})

The domain is sampled, points are grouped by the range bin containing f(x), and each bin contributes representative value × estimated measure.

Numerical qualification: the range-bin method below is a finite-grid approximation inspired by the Lebesgue definition. It is not a general exact Lebesgue-integral algorithm. Both methods depend on sampling resolution and range-bin width.

How the methods work

Riemann midpoint: I ≈ Δx Σᵢ f(a + (i + 1/2)Δx)
Range-bin estimate: I ≈ Σⱼ cⱼ · (number of sampled x with f(x) in bin j) · Δx

For a finite range partition, cⱼ is the midpoint of range bin j. In the convergence table, K is increased together with N so that range-quantization error does not remain fixed while the domain grid is refined. For the unbounded function 1/√x, the range is truncated at the largest sampled value and the first domain sample is kept away from zero; the approximation therefore has an additional truncation/grid effect.

Pathological examples and what numerical grids can/cannot show

  • Dirichlet function: D(x)=1 for rational x and 0 for irrational x. It is not Riemann-integrable, but it is Lebesgue-integrable with integral 0 because the rationals have measure zero. A finite floating-point grid consists of representable numbers and cannot meaningfully distinguish rational from irrational real inputs. The code therefore labels this experiment illustrative only; it must not be interpreted as a reliable numerical Lebesgue computation.
  • Thomae function: T(p/q)=1/q for p/q in lowest terms and 0 for irrational x. It is Riemann-integrable and its integral on [0,1] is 0. A floating-point implementation can only detect a limited set of rational representations, so the grid experiment is illustrative, not a proof or a fully reliable evaluation.

For bounded functions continuous except on a set of measure zero, such as the step functions here, the Riemann and Lebesgue integrals agree. For the examples that are Riemann-integrable, both numerical approaches should approach the same integral as the grid and range partition are refined, although their finite-resolution errors can differ.

Ex. 2 – Numerical Computation of the Normal CDF

The standard normal CDF is

Φ(x) = (1 / √(2π)) ∫₋∞ˣ exp(−t²/2) dt.

The antiderivative of exp(−t²/2) cannot be written using elementary functions. In differential algebra, Liouville's theorem gives criteria for an elementary antiderivative. For exp(−u²), an elementary antiderivative would require a rational function R satisfying R′(u) − 2uR(u) = 1; no rational function satisfies this identity. Thus a new special function is used.

The error function is defined by

erf(z) = (2 / √π) ∫₀ᶻ exp(−t²) dt

and gives the exact analytical representation

Φ(x) = ½ [1 + erf(x / √2)].

“Exact analytical representation” means an exact identity in terms of a special function. A computer still needs a numerical algorithm to evaluate erf or the integral to finite precision.

Three numerical approaches

1. Simpson's rule

Numerically integrates the normal density from 0 to |x| and uses symmetry: Φ(x)=0.5±∫₀^{|x|}φ(t)dt. This avoids an arbitrary finite lower cutoff and works for positive and negative x.

2. erf power series

Uses erf(z)=2/√π Σₖ₌₀∞ [(-1)ᵏ z²ᵏ⁺¹/(k!(2k+1))]. This converges for all finite z but can suffer cancellation and become inefficient for large |z|.

3. erfc-style approximation

Uses a compact Numerical-Recipes-style approximation to erf/erfc. It has a fixed computational cost and is fast, but is approximate rather than exact.

Accuracy and efficiency discussion

  • Simpson's rule is a general integration method. For a smooth density and enough even subintervals, it is accurate, but its cost grows with the number of intervals.
  • The power series is mathematically transparent and converges for every finite input. For large absolute inputs, terms can become very large before cancellation, so it is not the best general-purpose method.
  • The compact erf approximation uses a fixed number of arithmetic operations and is usually the fastest of these three methods. Its error is small but nonzero; the implementation should be checked against reference values.
  • For very negative x, computing 1−Φ(−x) can lose precision if Φ is close to 1. A production-quality library uses dedicated tail algorithms and complementary error functions.

Conclusions

  • Riemann sums partition the domain, while the Lebesgue-inspired finite-range method groups sampled domain points according to their function values.
  • For the bounded Riemann-integrable examples, the two integral definitions agree, and both numerical approximations should converge toward the same value as the partitions are refined.
  • Pathological examples show why measure theory is more general. However, finite floating-point sampling cannot establish the rational/irrational distinction required by the Dirichlet function.
  • The normal CDF has no elementary antiderivative, but the error function gives an exact special-function representation. Numerical algorithms are still needed because software must return finite-precision numbers.
  • No single numerical method is best for every input: the choice depends on accuracy requirements, input range, computational cost, and numerical stability.

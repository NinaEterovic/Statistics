HMWK 2 — Randomness Extraction & Leftover Hash Lemma

Advanced Cryptography & Information-Theoretic Security Foundations

1. Three Paradigms for Randomness Extraction

To overcome fundamental extraction impossibilities, three primary lines of research exist in cryptography:

  • Multiple Independent Sources (2-Source Extractors): Assumes two or more statistically independent entropy sources to enable deterministic extraction without extra setup.
  • Cryptographic Assumptions (Hash Functions): Applies cryptographic primitives (e.g., modeling hash functions as Random Oracles) under computational or structural assumptions.
  • Seeded Extraction: Introduces a short, uniform, independent random string (a "seed") to act as a catalyst for extracting uniform bits from any weak source.

2. Formal Security & Statistical Distance

  • Formal Security Condition: A seeded extractor requires that the joint distribution of the public seed \(S\) and extracted output \(\text{Ext}(S,X)\) is statistically \(\epsilon\)-close to a pair composed of \(S\) and an independent uniform string \(U_l\):
\((S, \text{Ext}(S,X)) \approx_\epsilon (S, U_l) \equiv U_{d+l}\)
  • Information-Theoretic Security: Because security is statistical, even a computationally unbounded adversary \(\mathcal{A}\) cannot distinguish the extracted output from pure uniform randomness with advantage greater than \(\epsilon\).
  • Statistical Distance Definition (\(SD\)): Defined via total variation distance:
\(SD(X; Y) = \frac{1}{2} \sum_z |\Pr[X = z] - \Pr[Y = z]| \le \epsilon\)

3. The Leftover Hash Lemma (LHL)

  • Core Significance: Demonstrates that pairwise independent hash families function as high-quality seeded extractors.
  • Setup: Let \(\mathcal{H} = \{h_S : \{0,1\}^m \rightarrow \{0,1\}^l\}_{S \in \{0,1\}^d}\) be a family of pairwise independent hash functions indexed by public seed \(S\).
  • Construction: Evaluating the hash function with seed \(S\) directly yields the extraction function \(\text{Ext}(S,X) = h_S(X)\).

HW1b — Statistical Foundations: MACs & Pairwise Independence

Message Authentication Codes, Affine Hash Functions, and Linear Algebra Proofs

1. Message Authentication Codes (MACs) & Security Bounds

Expanding into message integrity, authenticity, and statistical security bounds:

  • Adversary's Goal (Known-Pair Attack): Eve intercepts a valid transmitted pair \((m, \tau)\) where \(\tau = \text{Tag}(K, m)\). Without knowing the secret key \(K\), Eve attempts a forgery by generating a valid tag \(\tau'\) for a distinct message \(m' \ne m\).
  • \(\epsilon\)-Statistical Security Definition: A MAC scheme is defined as \(\epsilon\)-statistically secure if the success probability of a one-time forgery is strictly bounded:
\(\Pr[\tau' = \text{Tag}(K, m') \mid \tau = \text{Tag}(K, m)] \le \epsilon \quad (\text{e.g., } \epsilon = 2^{-80} \text{ or } 2^{-128})\)

2. Linear Algebra Proof of Pairwise Independence

Using affine hash functions over prime fields \(\mathbb{Z}_p\): \(h_{a,b}(m) = a \cdot m + b \pmod p\). To prove pairwise independence, we analyze the linear system:

\(\begin{pmatrix} m & 1 \\ m' & 1 \end{pmatrix} \begin{pmatrix} a \\ b \end{pmatrix} = \begin{pmatrix} \tau \\ \tau' \end{pmatrix} \pmod p\)

Since \(m \ne m'\), the matrix determinant is non-zero (\(\det = m - m' \ne 0\)). This guarantees that the inverse exists, yielding a unique key pair \((a,b)\) out of \(p^2\) possibilities:

\(\Pr_{a,b}[h_{a,b}(m) = \tau \land h_{a,b}(m') = \tau'] = \frac{1}{p^2} = \frac{1}{|\mathcal{T}|^2}\)

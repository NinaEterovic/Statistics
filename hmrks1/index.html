HMWK 1 — Public-Key Cryptography: Private Key to Public Key in Ethereum

1. Introduction & Notes

Elliptic-curve scalar multiplication can be viewed as a cryptographic one-way function. It is deterministic and easy to compute in the forward direction (private key k → public key Q = kG), while recovering k from Q is computationally difficult (based on the Elliptic Curve Discrete Logarithm Problem - ECDLP).

2. Toy Curve Parameters

  • Curve Equation: \(y^2 = x^3 + 7 \pmod{17}\)
  • Base Point (Generator): \(G = (1, 5)\)
  • Private Key: \(k = 6\)

3. Step-by-Step Computation (\(Q = 6G\))

  • 1G: \((1, 5)\)
  • 2G (Point Doubling): \((2, 10)\)
  • 3G: \((5, 9)\)
  • 4G: \((12, 1)\)
  • 5G: \((12, 16)\)
  • 6G: \((5, 8)\)

TOY PUBLIC KEY (Q): (5, 8)

4. Statistical Exploration

When repeating this experiment with different private keys k:

  • Distribution of coordinates: The resulting x and y coordinates appear pseudo-random and uniformly distributed across the finite field.
  • Avalanche-like behavior: A small change in the input private key drastically alters the output point due to the non-linear algebraic structure.
  • Comparison: Unlike cryptographic hash functions which compress arbitrary-length inputs, elliptic-curve public-key cryptography relies on hard mathematical group operations.

Cryptography & Applied Statistics

Comprehensive Overview: Perfect Secrecy, MACs, Pairwise Independence & Leftover Hash Lemma

1. Symmetric Encryption & Perfect Secrecy (Shannon)

Model: Alice wants to send message \(m \in \mathcal{M}\) to Bob using shared secret key \(k \in \mathcal{K}\) chosen uniformly at random (\(k \leftarrow \mathcal{K}\)).

\(\text{Enc} : \mathcal{K} \times \mathcal{M} \to \mathcal{C}, \quad \text{Dec} : \mathcal{K} \times \mathcal{C} \to \mathcal{M}\)
\(\text{Correctness: } \forall k \in \mathcal{K}, \forall m \in \mathcal{M}, \;\; \text{Dec}(k, \text{Enc}(k, m)) = m\)

Definition of Perfect Secrecy: An encryption scheme \(\Pi = (\text{Enc}, \text{Dec})\) is perfectly secret if for all message distributions, messages \(m\), and ciphertexts \(c\):

\(\Pr[M = m] = \Pr[M = m \mid C = c]\)

2. Message Authentication Codes (MACs) & Security

Unlike encryption (which hides content), MACs ensure integrity and authenticity over public channels using tags \(\tau = \text{Tag}(K, m)\).

  • Adversary's Goal (Eve): Intercepts a valid pair \((m, \tau)\) and attempts to forge a valid tag \(\tau'\) for a distinct message \(m' \ne m\).
  • \(\epsilon\)-Statistical Security: A MAC scheme is \(\epsilon\)-secure if the probability of a successful one-time forgery is bounded by a negligible value \(\epsilon\) (e.g., \(2^{-80}\) or \(2^{-128}\)):
\(\Pr[\tau' = \text{Tag}(K, m') \mid \tau = \text{Tag}(K, m)] \le \epsilon\)

3. Affine Hash Functions & Pairwise Independence

A concrete construction of a pairwise independent hash family over a prime field \(\mathbb{Z}_p\) (\(\lambda\)-bit prime):

\(h_{a,b}(m) = a \cdot m + b \pmod p \quad \text{where } (a,b) \in \mathcal{K} = \mathbb{Z}_p^2\)

Matrix Proof of Independence: For distinct messages \(m \ne m'\) and target tags \(\tau, \tau'\):

\(\begin{pmatrix} m & 1 \\ m' & 1 \end{pmatrix} \begin{pmatrix} a \\ b \end{pmatrix} = \begin{pmatrix} \tau \\ \tau' \end{pmatrix} \pmod p\)

Since \(m \ne m'\), the matrix determinant is non-zero, ensuring the inverse exists and yielding exactly 1 unique key pair out of \(p^2\):

\(\Pr_{a,b}[h_{a,b}(m) = \tau \land h_{a,b}(m') = \tau'] = \frac{1}{p^2} = \frac{1}{|\mathcal{T}|^2}\)

4. Seeded Extractors & Leftover Hash Lemma

Extracting uniform random bits from a weak entropy source \(X\) with min-entropy \(H_\infty(X) \ge k\) using a public seed \(S \in \{0,1\}^d\):

\(\text{Ext}(S, X) = h_S(X) \quad \implies \quad (S, \text{Ext}(S,X)) \approx_\epsilon (S, U_l)\)

Entropy Gap Requirement (LHL): To achieve an \(\epsilon\)-statistical distance bound, the min-entropy must satisfy:

\(k \ge l + 2 \log_2(1/\epsilon) - 2\)
